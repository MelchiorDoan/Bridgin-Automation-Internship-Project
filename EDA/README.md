# EDA notebook

Data quality checks and exploratory analysis of the Smart Home Energy Consumption dataset (100,000 readings, 500 homes).

- Data source: Kaggle, "Smart Home Energy Consumption" (mexwell)
- Notebook: 01_data_overview.ipynb
- To run: download the CSV from Kaggle and set the path in the first code cell. The data file is not stored in this repository.
